# Rabbi Steevax — published content and website

Everything Rabbi Steevax publishes, in one place: the weekly Torah studies read live by the
[iOS app](https://apps.apple.com/app/id6829267081), their audio, the paintings, and the website
**[rabbisteevax.com](https://rabbisteevax.com)** (GitHub Pages of this repository).

Generated automatically every Monday by the weekly pipeline (GitHub Actions, Claude API for the study, ElevenLabs for
the audio, checked against Sefaria). **Do not edit by hand**: the next run would overwrite the change. The podcast
itself is published on [podcast.rosenblum.ai](https://podcast.rosenblum.ai).

## Content (read by the app and the website)

| Path | What |
|---|---|
| `<portion-id>.json` | One study per weekly portion (e.g. `vayera.json`): passages, contradictions, readings, teachings, people, places, timeline, commentators' brief, quiz |
| `texts/<portion-id>.json` | The verses of each passage: Hebrew, English and French |
| `audio/` | Narration of each passage and the story of the portion, FR and EN (`5787-NN-<id>_…_fr.mp3`) |
| `illus/<portion-id>.jpg` | One painting per portion (16:9) |
| `_manifest.json` | Files and hashes: the app downloads only what changed |
| `_index.json`, `_calendar.json` | The 54 portions and their reading dates |
| `_torah.json`, `_library.json`, `_sages.json` | Torah overview, library, sages |
| `_kashrut.json` | Kosher guide |
| `_podcast.json`, `web/episodes.json` | Podcast episodes |
| `_themes.json`, `skins/` | Holiday skins (images, fonts, sounds) |

## Website

| Page | |
|---|---|
| `/` | Home: this week's portion, the 54 portions by book (✓ when available), the rabbi's video, app QR code |
| `/etude/` | The study of each portion (`#<portion-id>`), the podcast (`#pods`) and the library (`#bib`) |
| `/torah/`, `/calendrier/` | The five books, holidays and month-by-month calendar |
| `/cachere/` | Kosher guide |
| `/table/`, `/reglages/` | La table du Rav (badges) and settings: profile, language, skins, iCloud sync |
| `/app/` | Redirect to the App Store |
| `assistance.html`, `privacy.html`, `terms.html` | Support, privacy policy, terms (FR/EN) |

The pages are generated by the private `rabbi-steevax-ios` repository (`web/`). Progress made on the site stays in the
browser and can be synced with the app through iCloud (CloudKit, optional, from the settings page).

## Rules

- History is never rewritten: `main` refuses force-push and deletion.
- Texts come from Sefaria; translations: Bible du Rabbinat 1899 (FR), JPS (EN).
- Contact: contact@rabbisteevax.com
